# Photos — drop them here

Save each photo into this `images/` folder using the **exact filename** below
(all lowercase, `.jpg`). The site already points to these names, so once a file
is in place it appears automatically — no code changes needed. Any photo that is
missing simply shows a tasteful coloured placeholder, so nothing ever looks broken.

> Tip: keep files reasonably sized (long edge ~1600px, < ~400 KB each) so the
> site loads fast. JPEGs are ideal for photos.

## Still spare?

Any photo you don't have a slot for can be added by saving it here and copying one
`<figure class="gal">…</figure>` block in the gallery grid in `index.html`
(add `data-span="wide"` or `data-span="tall"` for a bigger tile).
