## Adding more

Save a new photo here, then add one `<figure class="gal">…</figure>` block inside
the relevant `.gallery__category` in `index.html` (or start a new category by
copying the whole `<div class="gallery__category">` block). Add
`data-span="wide"` or `data-span="tall"` on a `<figure>` for a bigger tile.
